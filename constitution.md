# Constituição do Projeto

1. Utilizar Python 3.14+ e pytest para os testes.
2. Manter o código simples, sem dependências desnecessárias.
3. Utilizar specs/checkout_frete.md como fonte única da verdade.
4. Executar uma tarefa por vez.
5. Criar os testes antes da implementação.
6. Referenciar REQ-01 e REQ-02 no código e nos testes.
7. Não adicionar funcionalidades sem especificação.
8. Atualizar primeiro a especificação quando uma regra mudar.
9. Manter especificação, código e testes no mesmo commit/PR.
